---

## Описание проекта
В данном проекте решается задача многоклассовой классификации текстов из датасета **20 Newsgroups**. Основной фокус сделан на исследовании качества выборочной классификации (отказ от ответа при низкой уверенности модели).

---

## Структура репозитория
- `requirements.txt` — список необходимых библиотек.
- `src/` — вспомогательные модули для загрузки данных и расчета метрик.
- `main.py` — главный скрипт для запуска экспериментов.
- `results/` — графики и результаты (включая Confusion Matrix).
